## English

**Quit shortcut, performance overlay, key remapping, four controller ports, display choice and updates from the launcher.** This is a release of **Digimon World 4 — Recomp**, a native port of Digimon World 4 (original Xbox, 2005) made by static recompilation. No emulator. Still early and experimental.

> ⚠️ **No game files included.** You need your own, legally obtained Digimon World 4 disc for the Xbox, **NTSC-U** (title ID `42410002`). Never share game files.

> **Only the beginning of the game has been tested:** Terminal Area (the lobby), Central Area, Death Valley and Humid Cave.

### What changed

Everything below is the same on Linux and Windows, and is set in the launcher.

- **Quit the game with a shortcut** (Controls → Quit the game). Fullscreen has no close button. Default: `Ctrl` + `Q` on the keyboard (at once), or `Back` + `Start` held for 1 second on any controller. Both can be changed (1 to 4 keys, 2 to 4 buttons) or turned off. Anything not saved inside the game is lost, as when closing the window.
- **Performance overlay** (Controls → Performance overlay): FPS, CPU and GPU in the top-left corner, on both graphics APIs and at any resolution. Default: `F2`, or `L3` + `R3` on the controller, show and hide it; it can also start visible. CPU is the average of all the computer's cores; GPU is the load of the whole card and reads `--` when the system does not report it.
- **Keyboard keys can be changed** (Controls → Keyboard as controller 1): click a key and press the new one. If it was already on another control, the two swap.
- **Four controller ports** (Controls → Controller ports), like the Xbox, for local multiplayer with up to 4 players. Controllers take the ports in the order the system reports them; the number can be lowered to 1.
- **Choose the display** (Graphics → Window → Display) the game opens on, windowed or fullscreen.
- **Updates** (Play → Updates). The launcher looks for a newer release on GitHub when it opens (at most once every 6 hours; it can be turned off) or with **Check for updates**. The **AppImage** and the **Windows `.zip`** then update themselves with **Update now**: the package is downloaded, its size and SHA-256 are checked against the release, and the launcher reopens on the new version. Nothing is installed unless you ask. The Linux `.tar.gz` only tells you and opens the release page.

### Coming from v0.4.1 or earlier

Those versions cannot update themselves: download this one once, the usual way. Saves and settings are kept (`~/.local/share/dw4-recomp/` on Linux, `%APPDATA%\dw4-recomp\` on Windows). From this version on, the launcher offers the next ones.

### Getting started on Windows

1. Download `DigimonWorld4-Recomp-v0.5.0-windows-x86_64.zip` below and extract **all of it** to any folder.
2. Open `DigimonWorld4-Recomp.exe`. The first time, Windows may warn that the program is unknown (SmartScreen): **More info → Run anyway**.
3. On the **Play** screen, choose the image (`.iso`) of your disc, or a folder with the disc already extracted.
4. Click **PLAY**.

**Requirements:** Windows 10 or 11, 64-bit, and a GPU with a working **Vulkan or OpenGL 3.3** driver.

### Getting started on Linux

1. Download `DigimonWorld4-Recomp-v0.5.0-x86_64.AppImage` below.
2. Make it executable (`chmod +x DigimonWorld4-Recomp-*.AppImage`) and open it.
3. On the **Play** screen, choose the image (`.iso`) of your disc, or a folder with the disc already extracted.
4. Click **PLAY**.

**Requirements:** Linux x86-64, glibc 2.38 or newer (Ubuntu 24.04+, Fedora 39+, Arch, SteamOS 3.6+), a GPU with a working **Vulkan or OpenGL 3.3** driver. If the AppImage does not start because FUSE is missing, run it with `--appimage-extract-and-run`, or use the `.tar.gz` (same content: unpack and run `./DigimonWorld4-Recomp`).

### Tested

On one machine only (NVIDIA GeForce RTX 5070, AMD Ryzen 7 5700X, two displays).

- **Played on Linux, from the source build:** the quit shortcut, the overlay, changed keys, the game with four ports and one controller, and the display choice.
- **Windows build under Wine:** the display choice was played; the quit shortcut and the overlay passed automated runs.
- **Automated, no window:** boot to the lobby matches the reference frames on Vulkan and OpenGL, on Linux and on the Windows build under Wine; the overlay was captured on both APIs at 4:3, 16:9 and 21:9.
- **Updates:** against a local server standing in for GitHub (reading the release, wrong hash, cancelling, a malicious `.zip`, swapping the AppImage, copying over a Windows install while keeping the user's files), plus the real request to GitHub from the Python of both packages. The Windows installer step ran under Wine.

### Known issues

New in this version:

- **More than one controller has not been tested**, so local multiplayer is unconfirmed. It is also unknown whether the game minds the empty ports; if it misbehaves, lower Controls → Controller ports.
- **A real update between two releases has not happened yet** (this is the first version that can update). On Windows, if copying the new files fails half way there is no rollback: the launcher tells you to download the package by hand. The checksum comes from the same release as the package: it protects against a corrupted download, not a tampered release.
- **Nothing here was tested on real Windows**, only under Wine. The GPU number for cards that are not NVIDIA uses Windows counters that have never run; it may read `--`.
- GPU use is known to work only on an NVIDIA card on Linux. AMD on Linux should work; Intel on Linux reads `--`.
- A key you assign to a control also triggers a shortcut that uses it (for example `Ctrl` or `Q`); the launcher does not warn.
- The display list is read when the launcher opens. On Wayland the compositor may ignore the position of a plain window; fullscreen follows the choice. Two mirrored displays cannot be told apart.
- Closing the game with the window's close button crashed on exit in one automated run inside a headless compositor; if the launcher says the game "closed with an error" after you close the window, nothing was lost. The quit shortcut does not go through that path.

Still open from earlier versions: the floor that darkens for a moment, the possible quit or freeze when skipping the intro movie with START, the widescreen interface pieces not yet seen (shops, choices, 2 to 4 players), and on Windows the file pickers, reading an `.iso` and the report, which were never exercised.

### Reporting a problem

In the launcher: **Support → Create report**, and attach the file to an issue at https://github.com/lorransouzaaguiar/Digimon-World-4-Recomp/issues. The report has no game files and not your home folder's name.

`SHA256SUMS-v0.5.0.txt` lists the SHA-256 of the three downloads.

## Português (Brasil)

**Atalho para fechar, mostrador de desempenho, troca de teclas, quatro portas de controle, escolha do monitor e atualização pelo launcher.** Este é um release do **Digimon World 4 — Recomp**, um port nativo de Digimon World 4 (Xbox original, 2005) feito por recompilação estática. Sem emulador. Ainda inicial e experimental.

> ⚠️ **Os arquivos do jogo não vêm junto.** Você precisa do seu próprio disco de Digimon World 4 para Xbox, obtido legalmente, **NTSC-U** (title ID `42410002`). Nunca compartilhe arquivos do jogo.

> **Só o começo do jogo foi testado:** Terminal Area (o lobby), Central Area, Death Valley e Humid Cave.

### O que mudou

Tudo abaixo vale igual no Linux e no Windows e é configurado no launcher.

- **Fechar o jogo por atalho** (Controles → Fechar o jogo). Em tela cheia não há botão de fechar. Padrão: `Ctrl` + `Q` no teclado (na hora), ou `Back` + `Start` segurados por 1 segundo em qualquer controle. Os dois podem ser trocados (1 a 4 teclas, 2 a 4 botões) ou desligados. O que não foi salvo dentro do jogo é perdido, como ao fechar a janela.
- **Mostrador de desempenho** (Controles → Mostrador de desempenho): FPS, CPU e GPU no canto de cima à esquerda, nas duas APIs gráficas e em qualquer resolução. Padrão: `F2`, ou `L3` + `R3` no controle, mostram e escondem; também pode já abrir visível. A CPU é a média de todos os núcleos do computador; a GPU é a ocupação da placa inteira e mostra `--` quando o sistema não informa.
- **Teclas do teclado trocáveis** (Controles → Teclado como controle 1): clique numa tecla e aperte a nova. Se ela já estava em outro comando, os dois trocam.
- **Quatro portas de controle** (Controles → Portas de controle), como no Xbox, para o multijogador local de até 4 jogadores. Os controles ocupam as portas na ordem em que o sistema os reconhece; dá para reduzir até 1.
- **Escolha do monitor** (Gráficos → Janela → Monitor) em que o jogo abre, em janela ou em tela cheia.
- **Atualizações** (Jogar → Atualizações). O launcher procura um release mais novo no GitHub ao abrir (no máximo uma vez a cada 6 horas; dá para desligar) ou pelo botão **Procurar atualização**. O **AppImage** e o **`.zip` de Windows** se atualizam sozinhos com **Atualizar agora**: o pacote é baixado, o tamanho e o SHA-256 são conferidos com os do release e o launcher reabre na versão nova. Nada é instalado sem você pedir. O `.tar.gz` de Linux só avisa e abre a página do release.

### Vindo da v0.4.1 ou de uma anterior

Essas versões não se atualizam sozinhas: baixe esta uma vez, do jeito de sempre. Saves e opções são mantidos (`~/.local/share/dw4-recomp/` no Linux, `%APPDATA%\dw4-recomp\` no Windows). Desta versão em diante, o launcher oferece as próximas.

### Como começar no Windows

1. Baixe `DigimonWorld4-Recomp-v0.5.0-windows-x86_64.zip` abaixo e extraia **tudo** em qualquer pasta.
2. Abra `DigimonWorld4-Recomp.exe`. Na primeira vez o Windows pode avisar que o programa é desconhecido (SmartScreen): **Mais informações → Executar assim mesmo**.
3. Na tela **Jogar**, escolha a imagem (`.iso`) do seu disco, ou uma pasta com o disco já extraído.
4. Clique em **JOGAR**.

**Requisitos:** Windows 10 ou 11, 64 bits, e placa de vídeo com driver **Vulkan ou OpenGL 3.3** funcionando.

### Como começar no Linux

1. Baixe `DigimonWorld4-Recomp-v0.5.0-x86_64.AppImage` abaixo.
2. Torne-o executável (`chmod +x DigimonWorld4-Recomp-*.AppImage`) e abra.
3. Na tela **Jogar**, escolha a imagem (`.iso`) do seu disco, ou uma pasta com o disco já extraído.
4. Clique em **JOGAR**.

**Requisitos:** Linux x86-64, glibc 2.38 ou mais nova (Ubuntu 24.04+, Fedora 39+, Arch, SteamOS 3.6+), placa de vídeo com driver **Vulkan ou OpenGL 3.3** funcionando. Se o AppImage não abrir por falta de FUSE, rode com `--appimage-extract-and-run`, ou use o `.tar.gz` (mesmo conteúdo: descompacte e rode `./DigimonWorld4-Recomp`).

### Testado

Em uma máquina só (NVIDIA GeForce RTX 5070, AMD Ryzen 7 5700X, dois monitores).

- **Jogado no Linux, a partir do código-fonte:** o atalho de fechar, o mostrador, teclas trocadas, o jogo com quatro portas e um controle, e a escolha do monitor.
- **Build de Windows no Wine:** a escolha do monitor foi jogada; o atalho de fechar e o mostrador passaram em execuções automáticas.
- **Automático, sem janela:** do boot ao lobby confere com os frames de referência em Vulkan e OpenGL, no Linux e no build de Windows pelo Wine; o mostrador foi capturado nas duas APIs em 4:3, 16:9 e 21:9.
- **Atualizações:** contra um servidor local fazendo as vezes do GitHub (leitura do release, hash errado, cancelar, `.zip` malicioso, troca do AppImage, cópia sobre uma instalação de Windows preservando os arquivos do usuário), mais a consulta de verdade ao GitHub pelo Python dos dois pacotes. O passo de instalação do Windows rodou no Wine.

### Problemas conhecidos

Novos nesta versão:

- **Mais de um controle não foi testado**, então o multijogador local não está confirmado. Também não se sabe se o jogo estranha as portas vazias; se estranhar, reduza em Controles → Portas de controle.
- **Uma atualização de verdade entre dois releases ainda não aconteceu** (esta é a primeira versão capaz de se atualizar). No Windows, se a cópia dos arquivos novos falhar no meio não há volta atrás: o launcher avisa para baixar o pacote à mão. O checksum vem do mesmo release que o pacote: protege de download corrompido, não de um release adulterado.
- **Nada disto foi testado em Windows de verdade**, só no Wine. O número da GPU em placas que não são NVIDIA usa contadores do Windows que nunca rodaram; pode aparecer `--`.
- O uso da GPU só foi visto funcionando numa NVIDIA no Linux. AMD no Linux deve funcionar; Intel no Linux mostra `--`.
- Uma tecla que você põe num comando também dispara um atalho que a use (por exemplo `Ctrl` ou `Q`); o launcher não avisa.
- A lista de monitores é lida quando o launcher abre. No Wayland o compositor pode ignorar a posição de uma janela comum; a tela cheia segue a escolha. Dois monitores espelhados não se distinguem.
- Fechar o jogo pelo botão de fechar da janela caiu na saída em uma execução automática dentro de um compositor sem tela; se o launcher disser que o jogo "fechou com erro" depois de você fechar a janela, nada foi perdido. O atalho de fechar não passa por esse caminho.

Continuam abertos de versões anteriores: o chão que escurece por um instante, o possível fechamento ou travamento ao pular o vídeo de abertura com START, as peças da interface em widescreen ainda não vistas (lojas, escolhas, 2 a 4 jogadores) e, no Windows, os diálogos de arquivo, a leitura de uma `.iso` e o relatório, que nunca foram exercitados.

### Relatar um problema

No launcher: **Suporte → Gerar relatório**, e anexe o arquivo a uma issue em https://github.com/lorransouzaaguiar/Digimon-World-4-Recomp/issues. O relatório não leva arquivos do jogo nem o nome da sua pasta pessoal.

### Checksums

`SHA256SUMS-v0.5.0.txt` traz o SHA-256 dos três downloads.
