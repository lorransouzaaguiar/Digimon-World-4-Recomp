## English

**Import Xbox saves from the launcher.** This is a release of **Digimon World 4 — Recomp**, a native port of Digimon World 4 (original Xbox, 2005) made by static recompilation. No emulator.

> ⚠️ **No game files included.** You need your own, legally obtained Digimon World 4 disc for the Xbox, **NTSC-U** (title ID `42410002`). Never share game files.

> **Only the beginning of the game has been played from a fresh save:** Terminal Area (the lobby), Central Area, Death Valley and Humid Cave. Several areas further on and one boss arena were played with an imported save. Nothing known stops you from finishing the game, but nobody has played it to the end yet.

### What changed

**Launcher**

- **Import… now takes Xbox saves of the game.** In **Saves & data → Import .zip…** you can pick a `.zip` that holds the `UDATA/42410002/` folder of a save made on a console or an emulator, or downloaded from a save site. The game used to refuse such a save with "This game is corrupted and cannot be used", because an Xbox save is signed with a key the port does not have; the launcher now signs it again for the port. Your current saves are backed up first, as with any import, and only the files of that save are replaced.
- The game has a single save file: importing one replaces the one in use (it stays in the backup, and **Import .zip…** on that backup brings it back).

Nothing changed in the game itself since v1.0.1; saves made by the port and backups made by the launcher work as before.

### Updating

- **Windows, from v0.5.0 or newer:** open the launcher and use **Update now** on the **Play** screen. Or download the `.zip` below and extract it as usual.
- **Linux AppImage, from v0.5.0 or newer:** **Update now** on the **Play** screen. The Linux `.tar.gz` only opens this page.
- **From v0.4.1 or earlier:** download the package below; those versions cannot update themselves.

Saves and settings are kept (`~/.local/share/dw4-recomp/` on Linux, `%APPDATA%\dw4-recomp\` on Windows).

### Getting started

- **Windows:** download `DigimonWorld4-Recomp-v1.1.0-windows-x86_64.zip`, extract all of it, open `DigimonWorld4-Recomp.exe` (SmartScreen: **More info → Run anyway**), choose the image (`.iso`) of your disc and click **PLAY**. Windows 10 or 11, 64-bit, a GPU with a Vulkan or OpenGL 3.3 driver.
- **Linux:** download `DigimonWorld4-Recomp-v1.1.0-x86_64.AppImage`, make it executable (`chmod +x`), open it, choose the image (`.iso`) of your disc and click **PLAY**. x86-64, glibc 2.38 or newer, a GPU with a Vulkan or OpenGL 3.3 driver. Without FUSE: `--appimage-extract-and-run`, or the `.tar.gz`.

### Tested

- **A real save downloaded from a save site:** signed again, it loads in the game (scripted, no window: Call Digimon → hard disk → lobby), and the author has been playing with it on Linux. The launcher's import produces that same file, byte for byte.
- **The import itself, scripted, no window:** made-up saves in the layouts such `.zip` files come in, damaged and foreign `.zip` files refused without touching the save, the backup of the previous save, and a launcher backup still importing as before.
- **The distance fog of v1.0.1, played by the author on Linux:** it looks normal in the several areas played since.
- **Reference frames, boot to lobby:** match with the packages of this version, AppImage and Windows build under Wine.

### Reporting a problem

In the launcher: **Support → Create report**, and attach the file to an issue at https://github.com/lorransouzaaguiar/Digimon-World-4-Recomp/issues. The report has no game files and not your home folder's name.
