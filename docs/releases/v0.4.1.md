## English

**The Windows build now has the launcher.** This is a release of **Digimon World 4 — Recomp**, a native port of Digimon World 4 (original Xbox, 2005) made by static recompilation. No emulator. Still early and experimental.

> ⚠️ **No game files included.** You need your own, legally obtained Digimon World 4 disc for the Xbox, **NTSC-U** (title ID `42410002`). Never share game files.

> **Only the beginning of the game has been tested:** Terminal Area (the lobby), Central Area, Death Valley and Humid Cave.

### What changed

**Windows**

- **Launcher.** v0.4.0 had no launcher: `run.bat` went straight into the game. Now you open `DigimonWorld4-Recomp.exe` and get the same launcher as on Linux: choose the disc image (`.iso`) or folder, graphics API (Vulkan or OpenGL), resolution, aspect ratio, 30/60 fps, fullscreen, vsync, saves (back up, export, import) and the support report.
- **No more copying game files by hand.** The launcher reads the `.iso` of your disc.
- **Saves, settings and logs moved to `%APPDATA%\dw4-recomp\`**, so they survive a new version. `run.bat` is gone.
- Nothing has to be installed: Python and Qt come inside the package (the download grew from 9 MB to about 53 MB).

**Linux**

- Nothing you can see. The launcher code gained the Windows parts; the Linux launcher behaves as before.

### Coming from v0.4.0 on Windows

Your saves were in the `save_data` folder next to `run.bat`. Copy that folder into `%APPDATA%\dw4-recomp\` (paste that in the Explorer address bar) before playing, or they will not show up.

### Getting started on Windows

1. Download `DigimonWorld4-Recomp-v0.4.1-windows-x86_64.zip` below and extract **all of it** to any folder.
2. Open `DigimonWorld4-Recomp.exe`. The first time, Windows may warn that the program is unknown (SmartScreen): **More info → Run anyway**.
3. On the **Play** screen, choose the image (`.iso`) of your disc, or a folder with the disc already extracted.
4. Click **PLAY**.

**Requirements:** Windows 10 or 11, 64-bit, and a GPU with a working **Vulkan or OpenGL 3.3** driver.

### Getting started on Linux

1. Download `DigimonWorld4-Recomp-v0.4.1-x86_64.AppImage` below.
2. Make it executable (`chmod +x DigimonWorld4-Recomp-*.AppImage`) and open it.
3. On the **Play** screen, choose the image (`.iso`) of your disc, or a folder with the disc already extracted.
4. Click **PLAY**.

**Requirements:** Linux x86-64, glibc 2.38 or newer (Ubuntu 24.04+, Fedora 39+, Arch, SteamOS 3.6+), a GPU with a working **Vulkan or OpenGL 3.3** driver. If the AppImage does not start because FUSE is missing, run it with `--appimage-extract-and-run`, or use the `.tar.gz` (same content: unpack and run `./DigimonWorld4-Recomp`).

Saves, settings and logs are kept in `~/.local/share/dw4-recomp/`. Saves from earlier versions keep working.

### Tested

On one machine only (NVIDIA GeForce RTX 5070, AMD Ryzen 7 5700X).

**Windows build:**

- The game (same code as v0.4.0) was played on real Windows 11 with v0.4.0, started from `run.bat`.
- The launcher, under Wine 11.22 only, with the files taken from this `.zip`: it opens, all five screens draw correctly, and starting the game from it reaches the lobby with the same reference frames as the Linux build, on Vulkan and on OpenGL.

**Linux:** automated runs from boot to the lobby match the reference frames on Vulkan and on OpenGL, started by the launcher inside the AppImage of this release. This exact build was not played with a window.

### Known issues

Windows build:

- **The launcher was not tested on real Windows.** Not exercised at all, even under Wine: the file pickers (disc image, folder, saves `.zip`), reading an `.iso`, and the report.
- The first start can take a few seconds while Windows scans the new files.
- Performance under Wine was a little below the Linux build in heavy areas; not measured on real Windows by us.
- If the game hangs, the log does not yet say where each thread was (it does on Linux).
- The keyboard as a controller was not tested on this build.

Both systems:

- All the known issues of v0.3.2 apply: the floor that darkens for a moment, the possible quit or freeze when skipping the intro movie with START, and the widescreen interface pieces not yet seen (shops, choices, 2 to 4 players).

### Reporting a problem

In the launcher, open **Support → Create report** and attach the text file to an issue. Do not attach game files.

## Português (Brasil)

**O build de Windows agora tem o launcher.** Este é um release do **Digimon World 4 — Recomp**, um port nativo de Digimon World 4 (Xbox original, 2005) feito por recompilação estática. Não é um emulador. Ainda inicial e experimental.

> ⚠️ **Os arquivos do jogo não vêm junto.** Você precisa do seu próprio disco de Digimon World 4 para Xbox, obtido legalmente, versão **NTSC-U** (title ID `42410002`). Nunca compartilhe arquivos do jogo.

> **Só o começo do jogo foi testado:** Terminal Area (o lobby), Central Area, Death Valley e Humid Cave.

### O que mudou

**Windows**

- **Launcher.** A v0.4.0 não tinha launcher: o `run.bat` entrava direto no jogo. Agora você abre `DigimonWorld4-Recomp.exe` e tem o mesmo launcher do Linux: escolher a imagem do disco (`.iso`) ou a pasta, API gráfica (Vulkan ou OpenGL), resolução, proporção, 30/60 quadros, tela cheia, vsync, saves (backup, exportar, importar) e o relatório de suporte.
- **Não é mais preciso copiar os arquivos do jogo à mão.** O launcher lê a `.iso` do seu disco.
- **Saves, opções e logs passaram para `%APPDATA%\dw4-recomp\`**, para sobreviverem a uma versão nova. O `run.bat` deixou de existir.
- Nada precisa ser instalado: o Python e o Qt vêm dentro do pacote (o download cresceu de 9 MB para cerca de 53 MB).

**Linux**

- Nada que você veja. O código do launcher ganhou as partes de Windows; o launcher do Linux se comporta como antes.

### Vindo da v0.4.0 no Windows

Os seus saves ficavam na pasta `save_data` ao lado do `run.bat`. Copie essa pasta para `%APPDATA%\dw4-recomp\` (cole isso na barra de endereços do Explorador) antes de jogar, ou eles não aparecem.

### Como começar no Windows

1. Baixe `DigimonWorld4-Recomp-v0.4.1-windows-x86_64.zip` abaixo e extraia **tudo** para uma pasta qualquer.
2. Abra `DigimonWorld4-Recomp.exe`. Na primeira vez o Windows pode avisar que o programa é desconhecido (SmartScreen): **Mais informações → Executar assim mesmo**.
3. Na tela **Jogar**, escolha a imagem (`.iso`) do seu disco, ou uma pasta com o disco já extraído.
4. Clique em **JOGAR**.

**Requisitos:** Windows 10 ou 11, 64 bits, e placa de vídeo com driver **Vulkan ou OpenGL 3.3** funcionando.

### Como começar no Linux

1. Baixe `DigimonWorld4-Recomp-v0.4.1-x86_64.AppImage` abaixo.
2. Torne o arquivo executável (`chmod +x DigimonWorld4-Recomp-*.AppImage`) e abra.
3. Na tela **Jogar**, escolha a imagem (`.iso`) do seu disco, ou uma pasta com o disco já extraído.
4. Clique em **JOGAR**.

**Requisitos:** Linux x86-64, glibc 2.38 ou mais nova (Ubuntu 24.04+, Fedora 39+, Arch, SteamOS 3.6+) e placa de vídeo com driver **Vulkan ou OpenGL 3.3** funcionando. Se o AppImage não abrir por falta do FUSE, rode com `--appimage-extract-and-run`, ou use o `.tar.gz` (mesmo conteúdo: extraia e rode `./DigimonWorld4-Recomp`).

Saves, opções e logs ficam em `~/.local/share/dw4-recomp/`. Os saves das versões anteriores continuam funcionando.

### Testado

Em uma máquina só (NVIDIA GeForce RTX 5070, AMD Ryzen 7 5700X).

**Build de Windows:**

- O jogo (mesmo código da v0.4.0) foi jogado em Windows 11 de verdade com a v0.4.0, iniciado pelo `run.bat`.
- O launcher, só dentro do Wine 11.22, com os arquivos tirados deste `.zip`: abre, as cinco telas são desenhadas certo, e o jogo iniciado por ele chega ao lobby com os mesmos frames de referência do build de Linux, em Vulkan e em OpenGL.

**Linux:** rodadas automáticas do boot até o lobby batem com os frames de referência em Vulkan e em OpenGL, iniciadas pelo launcher de dentro do AppImage deste release. Este build exato não foi jogado com janela.

### Problemas conhecidos

Build de Windows:

- **O launcher não foi testado em Windows de verdade.** Nunca exercitados, nem no Wine: as janelas de escolher arquivo (imagem do disco, pasta, `.zip` de saves), a leitura de uma `.iso` e o relatório.
- A primeira abertura pode levar alguns segundos enquanto o Windows examina os arquivos novos.
- O desempenho no Wine ficou um pouco abaixo do build de Linux nas áreas pesadas; em Windows de verdade não foi medido por nós.
- Se o jogo travar, o log ainda não diz onde cada thread estava (no Linux diz).
- O teclado como controle não foi testado neste build.

Nos dois sistemas:

- Valem todos os problemas conhecidos da v0.3.2: o chão que escurece por um instante, a possível saída ou travamento ao pular o vídeo de abertura com START, e as peças da interface em widescreen ainda não vistas (lojas, escolhas, 2 a 4 jogadores).

### Como relatar um problema

No launcher, abra **Suporte → Criar relatório** e anexe o arquivo de texto a uma issue. Não anexe arquivos do jogo.
