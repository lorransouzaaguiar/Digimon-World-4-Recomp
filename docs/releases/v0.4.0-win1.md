## English

**Experimental Windows preview** of **Digimon World 4 — Recomp**, a native port of Digimon World 4 (original Xbox, 2005) made by static recompilation. No emulator.

> ⚠️ **No game files included.** You need your own, legally obtained Digimon World 4 disc for the Xbox, **NTSC-U** (title ID `42410002`). Never share game files.

> 🧪 **This is a test build, for testers.** The Windows build has so far only run on Linux, inside Wine. **It has not been tested on a real Windows machine yet** — that is what this pre-release is for.

> **Linux players: nothing new here.** Keep using [v0.3.2](https://github.com/lorransouzaaguiar/Digimon-World-4-Recomp/releases/tag/v0.3.2). This pre-release has no Linux download.

### What is in it

- `dw4_recomp.exe`, the game built for Windows x86-64 (cross-compiled with MinGW-w64).
- The same two renderers as on Linux: **Vulkan** (default) and **OpenGL 3.3**. No DirectX.
- Window, controller and audio through SDL2, as on Linux.
- Internal resolution (480p to 4K) and aspect ratio (4:3, 16:9, 21:9), as on Linux.
- **No launcher yet.** The options are a few lines at the top of `run.bat`, and the game files have to be copied by hand (there is nothing on Windows yet to read the `.iso`).

### Getting started

1. Download `DigimonWorld4-Recomp-v0.4.0-win1-windows-x86_64.zip` below and extract all of it to a folder you can write to (not "Program Files").
2. Copy the files of your own extracted disc into the `game_data` folder: `default.xbe`, `area.afs`, `ndmw.afs`, `ndmw.igb`.
3. Double-click `run.bat`. The first time, Windows may warn that the program is unknown (SmartScreen): **More info → Run anyway**.

To change the graphics API, resolution, aspect ratio, 30/60 fps, fullscreen or vsync, open `run.bat` in Notepad and edit the lines at the top.

**Requirements:** Windows 10 or 11, 64-bit, and a GPU with a working **Vulkan or OpenGL 3.3** driver.

Saves are kept in `save_data\` and one log per session in `logs\`, both next to `run.bat`.

### Tested

Only on Linux, with Wine 11.22, on one machine (NVIDIA GeForce RTX 5070, AMD Ryzen 7 5700X, CachyOS):

- Automated runs from boot to the lobby match the same reference frames as the Linux build, on Vulkan and on OpenGL, including with the `.exe` taken from this `.zip`.
- Played with a window on Vulkan: lobby, Central Area, unlocking Death Valley and the tutorial, in 4:3 at 30 fps and in 16:9 1440p at 60 fps. Image, sound and a PlayStation 4 controller worked; resizing and fullscreen worked.

### Known issues

- **Not tested on real Windows.** Different video drivers, antivirus, SmartScreen, display scaling and real audio devices have never been exercised.
- **OpenGL has not been played with a window**, only checked by automated runs.
- **Performance under Wine is a little below the Linux build** in heavy areas (about 55 fps in the busiest part of Central Area at 1440p, with short dips to 45 in Death Valley, where the Linux build holds 60). Whether this is Wine or the Windows build itself is not known yet.
- The keyboard as a controller was not tested on this build.
- A console window stays open next to the game; that is expected for now.
- If the game hangs, the log does not yet say where each thread was (it does on Linux).
- `run.bat` uses a fixed window size taken from the resolution; on a small monitor pick a lower resolution or fullscreen.
- All the known issues of v0.3.2 apply: the floor that darkens for a moment, the possible quit or freeze when skipping the intro movie with START, and only the beginning of the game has been tested (Terminal Area, Central Area, Death Valley, Humid Cave).

### Reporting a problem

Open an issue and attach the newest file from the `logs\` folder. Say your Windows version, your GPU and which options you changed in `run.bat`. Do not attach game files.

`SHA256SUMS-v0.4.0-win1-windows.txt` lists the SHA-256 of the download.

## Português (Brasil)

**Prévia experimental para Windows** do **Digimon World 4 — Recomp**, um port nativo de Digimon World 4 (Xbox original, 2005) feito por recompilação estática. Não é um emulador.

> ⚠️ **Os arquivos do jogo não vêm junto.** Você precisa do seu próprio disco de Digimon World 4 para Xbox, obtido legalmente, versão **NTSC-U** (title ID `42410002`). Nunca compartilhe arquivos do jogo.

> 🧪 **Esta é uma versão de teste, para quem quer testar.** O build de Windows até agora só rodou no Linux, dentro do Wine. **Ainda não foi testado em um Windows de verdade** — é para isso que este pré-lançamento existe.

> **Quem joga no Linux: não há nada novo aqui.** Continue na [v0.3.2](https://github.com/lorransouzaaguiar/Digimon-World-4-Recomp/releases/tag/v0.3.2). Este pré-lançamento não tem download para Linux.

### O que vem

- `dw4_recomp.exe`, o jogo compilado para Windows x86-64 (compilação cruzada com MinGW-w64).
- Os mesmos dois renderizadores do Linux: **Vulkan** (padrão) e **OpenGL 3.3**. Nada de DirectX.
- Janela, controle e áudio pela SDL2, como no Linux.
- Resolução interna (480p a 4K) e proporção (4:3, 16:9, 21:9), como no Linux.
- **Ainda sem launcher.** As opções são algumas linhas no começo do `run.bat`, e os arquivos do jogo têm de ser copiados à mão (ainda não há nada no Windows que leia a `.iso`).

### Como começar

1. Baixe `DigimonWorld4-Recomp-v0.4.0-win1-windows-x86_64.zip` abaixo e extraia tudo para uma pasta em que você possa gravar (não dentro de "Arquivos de Programas").
2. Copie os arquivos do seu disco, já extraído, para a pasta `game_data`: `default.xbe`, `area.afs`, `ndmw.afs`, `ndmw.igb`.
3. Dê dois cliques em `run.bat`. Na primeira vez o Windows pode avisar que o programa é desconhecido (SmartScreen): **Mais informações → Executar assim mesmo**.

Para trocar a API gráfica, a resolução, a proporção, 30/60 quadros, tela cheia ou vsync, abra o `run.bat` no Bloco de Notas e edite as linhas do começo.

**Requisitos:** Windows 10 ou 11, 64 bits, e placa de vídeo com driver **Vulkan ou OpenGL 3.3** funcionando.

Os saves ficam em `save_data\` e há um log por partida em `logs\`, as duas pastas ao lado do `run.bat`.

### Testado

Só no Linux, com o Wine 11.22, em uma máquina (NVIDIA GeForce RTX 5070, AMD Ryzen 7 5700X, CachyOS):

- Rodadas automáticas do boot até o lobby batem com os mesmos frames de referência do build de Linux, em Vulkan e em OpenGL, inclusive com o `.exe` tirado deste `.zip`.
- Jogado com janela em Vulkan: lobby, Central Area, liberação do Death Valley e tutorial, em 4:3 a 30 fps e em 16:9 1440p a 60 fps. Imagem, som e um controle de PlayStation 4 funcionaram; redimensionar e tela cheia funcionaram.

### Problemas conhecidos

- **Não testado em Windows de verdade.** Drivers de vídeo diferentes, antivírus, SmartScreen, escala de tela e dispositivos de áudio reais nunca foram exercitados.
- **O OpenGL não foi jogado com janela**, só conferido por rodadas automáticas.
- **O desempenho no Wine fica um pouco abaixo do build de Linux** nas áreas pesadas (cerca de 55 fps no trecho mais cheio da Central Area em 1440p, com quedas curtas a 45 no Death Valley, onde o build de Linux segura 60). Ainda não se sabe se isso é do Wine ou do próprio build de Windows.
- O teclado como controle não foi testado neste build.
- Uma janela de console fica aberta ao lado do jogo; por enquanto é o esperado.
- Se o jogo travar, o log ainda não diz onde cada thread estava (no Linux diz).
- O `run.bat` usa um tamanho de janela fixo tirado da resolução; em monitor pequeno escolha uma resolução menor ou tela cheia.
- Valem todos os problemas conhecidos da v0.3.2: o chão que escurece por um instante, a possível saída ou travamento ao pular o vídeo de abertura com START, e só o começo do jogo foi testado (Terminal Area, Central Area, Death Valley, Humid Cave).
